# Portfolio

Personal portfolio site for **Tarun Deep Reddy B V** — AI/ML engineer and
researcher. Built with [Astro](https://astro.build), it covers current work,
past research experience, and shipped projects.

This repository is a public record of the project. The source code and media
assets live in a private repository and aren't published here — see
[Source](#source) below.

## Sections

- **Home** — introduction and quick links
- **Experience** — past research roles, including AI/ML research at SRM
  (facial-recognition attendance pipeline, bias mitigation, a paper accepted
  at ICCP 2026) and current MSCS coursework at USC
- **Work** — the multimodal, autonomous agentic AI system currently being
  built at USC, plus two in-progress projects (ORION, APEX)
- **Projects** — shipped and in-progress work, including
  [SKYNET](https://github.com/Tarun7981448226/SKYNET-AI), a 24/7 autonomous
  job-intelligence pipeline
- **Contact** — ways to get in touch

## Tech stack

- [Astro](https://astro.build) — static site generation
- Vanilla CSS with a token-based light/dark theme system
- No client-side framework — plain, progressively-enhanced JavaScript for
  interactive components (tabs, contact doorways, theme toggle)
